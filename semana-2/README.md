# Semana 2: Análisis comercial avanzado de Aurincy con Excel

## 📌 Descripción del proyecto

Proyecto de análisis de datos desarrollado con Microsoft Excel, utilizando como caso de estudio a **Aurincy**, un emprendimiento de jabones artesanales.

En esta segunda etapa se trabaja con una base de datos simulada de 500 registros, diseñada para analizar el comportamiento comercial del negocio desde diferentes perspectivas: ventas, productos, rentabilidad, clientes, canales de venta y costos de envío.

El proyecto integra herramientas de análisis y visualización de Excel para transformar los datos en información útil para la toma de decisiones comerciales.

> **Nota:** Los pedidos, clientes, costos y datos logísticos son simulados con fines educativos. Los precios de venta se basan en el catálogo original de Aurincy. Los resultados no representan ventas reales del negocio.

## 🎯 Objetivos

- Analizar el comportamiento de las ventas durante el período estudiado.
- Identificar los productos con mayor volumen de ventas e ingresos.
- Comparar la rentabilidad de los productos.
- Evaluar el comportamiento de los clientes y sus segmentos.
- Analizar el rendimiento de los canales de venta.
- Examinar la distribución geográfica de los pedidos.
- Evaluar los costos de envío y su cobertura.
- Construir un dashboard interactivo para facilitar la interpretación de los resultados.

## 📊 Datos utilizados

La base de datos contiene **500 registros simulados**, correspondientes al período comprendido entre enero y octubre de 2026.

Está organizada en las siguientes hojas:

| Hoja | Contenido |
|---|---|
| Ventas | Pedidos, fechas, productos, cantidades, descuentos, ventas, costos y logística. |
| Productos | Catálogo, precios de venta y costos unitarios. |
| Clientes | Identificación, ubicación geográfica y segmento de clientes. |
| Resumen | Preguntas de negocio y aspectos del análisis. |

## 🛠️ Herramientas y funcionalidades

- Tablas dinámicas.
- Gráficos dinámicos.
- Segmentación de datos.
- Línea de tiempo.
- Gráficos combinados.
- Dashboard interactivo.
- Análisis de ventas y rentabilidad.
- Análisis geográfico por provincia.
- Campos calculados en tablas dinámicas.

## 📈 Análisis desarrollados

### 1. Análisis de productos
- Cantidad de unidades vendidas.
- Ventas netas por producto.
- Margen bruto por producto.
- Margen bruto porcentual.
- Resultado después de costos de envío.

### 2. Análisis comercial
- Ventas netas por categoría.
- Cantidad de pedidos y ventas por canal.
- Evolución de las ventas en el tiempo.
- Descuentos aplicados.

### 3. Análisis de clientes
- Distribución por segmento.
- Comportamiento de compra.
- Distribución geográfica de los clientes.

### 4. Análisis logístico
- Costos de envío.
- Envíos cobrados a los clientes.
- Balance entre costos y cobros de envío.
- Porcentaje de cobertura de los costos logísticos.
